# Weekly Research Plan

Use this file to keep each week focused. Update this before collecting new papers.

## Weekly Routine

Every week, update these four files first:

1. `00_project_management/weekly_research_plan.md`
2. `02_literature_search/search_log.csv`
3. `05_synthesis_matrices/evidence_to_claim_matrix.csv`
4. `00_project_management/decision_log.md`

## Current Week

### Week Goal

Complete one coherent literature block rather than collecting papers randomly.

Suggested first block: pseudo-labeling and knowledge distillation for low-resource ASR.

### Minimum Output

- 20 papers screened.
- 8 papers fully noted using `04_paper_notes/paper_note_template.md`.
- 1 synthesis matrix updated.
- 1 draft subsection written or revised.
- 3 claims added to `05_synthesis_matrices/evidence_to_claim_matrix.csv`.
- 1 reviewer-risk entry added to `11_quality_control/reviewer_objection_log.md`.

### Active Tasks

| Task | Target File | Status | Notes |
|---|---|---|---|
| Define this week's search block | `weekly_research_plan.md` | Not started | Choose one method family or evaluation problem. |
| Log database searches | `02_literature_search/search_log.csv` | Not started | Record query, database, date, and screening result. |
| Create paper notes | `04_paper_notes/` | Not started | Use the common paper-note template. |
| Update claim evidence | `05_synthesis_matrices/evidence_to_claim_matrix.csv` | Not started | No major claim enters the manuscript without a row. |
| Record decisions | `00_project_management/decision_log.md` | Not started | Log scope, title, taxonomy, inclusion, and table changes. |
