# Submission Package

## Purpose

This folder is reserved for the final Artificial Intelligence Review submission package.

## Springer Nature LaTeX Upload Rule

For Springer Nature LaTeX upload, avoid nested folders. Before submission, copy the required files into one flat folder or ZIP archive:

- `main.tex`
- `sn-jnl.cls`
- Required `.bst` files, especially `sn-basic.bst`
- `references.bib` or a generated `.bbl` file
- All figure files
- Compiled PDF

## Do Not Place Here

- Draft working files.
- Literature PDFs.
- Notes not intended for submission.
- Unused figures or old manuscript versions.

## Final Check

Before upload, confirm that the flat submission folder compiles with `pdflatex` and contains no subfolders.
