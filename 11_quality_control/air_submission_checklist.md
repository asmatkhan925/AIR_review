# AIR Submission Checklist

Use this checklist before preparing the final Artificial Intelligence Review submission package.

## Title Page

- [ ] Title is concise and informative.
- [ ] Author names are correct.
- [ ] Affiliations include institution, department if needed, city, and country.
- [ ] Corresponding author email is active.
- [ ] ORCID is added if available.

## Abstract And Keywords

- [ ] Abstract is 150-250 words.
- [ ] Abstract has no undefined abbreviations.
- [ ] Abstract has no unspecified references.
- [ ] 4-6 keywords are included.

## Manuscript Structure

- [ ] Decimal headings are used.
- [ ] No more than three heading levels are used.
- [ ] Abbreviations are defined at first mention.
- [ ] Footnotes are used only where necessary.
- [ ] Acknowledgments are separate from the main text if required.

## References

- [ ] References are cited by author and year.
- [ ] Reference list includes only cited works.
- [ ] Reference entries are alphabetized.
- [ ] DOI links are included where available.
- [ ] `references.bib` is deduplicated and complete.

## Tables And Figures

- [ ] Tables are cited in numerical order.
- [ ] Figures are cited in numerical order.
- [ ] Each table has a clear caption.
- [ ] Each figure has a caption in the manuscript text.
- [ ] Permissions are checked for reused figures or tables.
- [ ] Figure files follow Springer naming and quality expectations.

## Declarations

- [ ] Statements and Declarations section is included.
- [ ] Funding statement is included.
- [ ] Competing interests statement is included.
- [ ] Data availability statement is included where needed.
- [ ] AI assistance is documented if required by the final journal policy.

## LaTeX Submission

- [ ] Source files are editable.
- [ ] `main.tex` compiles with `pdflatex`.
- [ ] `sn-jnl.cls` is included.
- [ ] Required `.bst` file is included.
- [ ] `references.bib` or `.bbl` is included.
- [ ] Final LaTeX submission folder is flat, with no nested figure or bibliography folders.
