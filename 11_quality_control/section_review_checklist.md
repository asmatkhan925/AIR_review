# Section Review Checklist

For each section, check:

- Does it have a clear purpose?
- Does it synthesize rather than list papers?
- Does it connect to the main review argument?
- Are factual claims supported?
- Are limitations discussed?
- Does it transition clearly from the previous section?
- Does it prepare the reader for the next section?
