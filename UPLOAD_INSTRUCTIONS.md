# Upload Instructions

This package contains replacement or new files for the AIR_review GitHub repository.

## How to Use

1. Download and unzip `AIR_review_update_package.zip`.
2. Copy the folders and files into the root of your local `AIR_review` repository.
3. Let the new files overwrite the existing files when names match.
4. Commit the changes with a message such as:

```bash
git add .
git commit -m "Refocus review toward foundation-model-era low-resource ASR"
git push
```

## Important Note

The package intentionally does not overwrite your full manuscript files in `12_manuscript/`. The manuscript should be updated only after the scope, research questions, outline, search strategy, and synthesis matrices are stable.
