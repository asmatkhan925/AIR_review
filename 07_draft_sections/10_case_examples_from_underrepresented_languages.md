# Case Examples from Underrepresented Languages

## Purpose

This file replaces the idea of a single Pashto-focused case-study section. The final manuscript may include short case boxes or examples from several underrepresented languages. Pashto can be included as one example, but it should not define the scope of the review.

## Why Case Examples Are Useful

Case examples can show that low-resource ASR problems are not abstract. They appear differently across languages, scripts, regions, domains, and communities. A carefully selected set of examples can strengthen the review without making it language-specific.

## Candidate Case Example Types

### Case Box 1: Pashto and Arabic-derived script normalization

Use Pashto as an example of how script variation, dialectal pronunciation, telephony speech, and transcript normalization affect low-resource ASR. Emphasize the general lesson: orthographic normalization changes the effective label space and evaluation comparability.

### Case Box 2: Scottish Gaelic and practical low-resource adaptation

Use Scottish Gaelic or a similar language as an example of how strong multilingual models still require careful data preparation, normalization, and adaptation.

### Case Box 3: Arabic dialects and dialect-aware ASR

Use Arabic dialect ASR to illustrate dialect mismatch, code-switching, and the limitations of pooled WER.

### Case Box 4: African languages and resource inequity

Use Yoruba, Hausa, Swahili, Amharic, or other African-language ASR studies to discuss resource imbalance, multilingual transfer, and benchmark gaps.

### Case Box 5: Indigenous or endangered languages

Use Indigenous-language ASR examples to discuss community-centered data, small corpora, ethics, and deployment constraints.

### Case Box 6: Low-resource AVSR

Use low-resource AVSR studies to discuss video-data scarcity, synchronization, face/mouth extraction, and audio-visual robustness.

## How to Use Pashto

Pashto should be used selectively for:
- orthographic normalization;
- Arabic-derived script variation;
- dialect imbalance;
- telephony noise;
- pseudo-label reliability;
- multi-teacher distillation;
- AVSR pipeline challenges.

Pashto should not be presented as:
- the main topic of the review;
- the only case study;
- proof that a method works for all low-resource languages;
- a replacement for broad cross-language synthesis.

## Suggested Manuscript Placement

Case examples can appear as boxed inserts in:
- Section 4: What makes ASR low-resource?
- Section 8: Data-centric approaches
- Section 9: Evaluation and reproducibility
- Section 11: Multimodal, Speech-LLM, and LLM-assisted low-resource ASR
