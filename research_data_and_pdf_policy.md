# Research Data And PDF Policy

## Purpose

Keep the repository legally clean, lightweight, and traceable.

## Literature PDFs

- Do not commit copyrighted PDFs.
- Store PDFs locally in ignored folders such as `local_pdfs/`, `papers_pdf/`, or `copyrighted_pdfs/`.
- Store only paper metadata, structured notes, citations, and official links in Git.
- Use DOI, arXiv ID, ACL Anthology ID, ISCA link, publisher URL, or dataset URL for traceability.

## Dataset Files

- Do not commit dataset files unless the license explicitly permits redistribution.
- Record dataset metadata, access instructions, license notes, and citations instead of raw data.
- Keep large data outside Git. Use Git LFS only if there is a clear need and the license permits versioned storage.

## Generated Files

- Generated PDFs and LaTeX build artifacts are ignored.
- Final submission PDFs may be created locally but should not be committed unless there is a deliberate release reason.

## Notes

When uncertain about rights, store a citation and access note rather than the file itself.
