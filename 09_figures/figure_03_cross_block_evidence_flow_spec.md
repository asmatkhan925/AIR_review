## Main Argument and Purpose

Low-resource ASR evidence should flow from resource and language conditions into model family, adaptation path, supervision path, and evaluation. Evaluation is not only the endpoint; it feeds back into resource design, adaptation comparison, supervision reliability, and future agenda setting.

## Visual Content

The polished draft uses three dominant columns:

1. Resource and language.
2. Model and supervision.
3. Evaluation and agenda.

Within these columns, concise nodes show resource condition, language condition, documentation controls, model family, adaptation path, supervision path, evaluation protocol, robustness evidence, and future agenda. Feedback arrows are deliberately sparse to avoid implying a fully exhaustive process model.
