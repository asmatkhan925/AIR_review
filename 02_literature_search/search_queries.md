# Search Queries

## Search Strategy

Use these queries across Google Scholar, Semantic Scholar, IEEE Xplore, ACM Digital Library, ISCA Archive, ACL Anthology, arXiv, SpringerLink, ScienceDirect, and other relevant databases.

Prioritize 2019–2026, with emphasis on 2022–2026. Include older papers only when foundational.
