# Database Sources

| Source | Use | Notes |
|---|---|---|
| Google Scholar | Broad discovery and citation chaining | Record exact query and date. |
| Semantic Scholar | Metadata, related papers, and citation graph | Useful for quick triage. |
| IEEE Xplore | Signal processing and ASR papers | Check venue quality. |
| ACM Digital Library | Computing and multimodal papers | Use targeted queries. |
| ACL Anthology | Speech/NLP and ASR-related proceedings | Especially useful for multilingual and low-resource work. |
| ISCA Archive | Interspeech and speech science papers | Essential for ASR. |
| SpringerLink | Review articles and journal papers | Relevant to Artificial Intelligence Review context. |
| ScienceDirect | Journal articles | Verify access and citation details. |
| arXiv | Recent preprints | Mark preprint status carefully. |
| Papers With Code | Benchmarks and implementation links | Use for triangulation, not as a primary citation alone. |
